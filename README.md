A clean, responsive web app to calculate and display student academic performance across 5 subjects — with grade breakdown, pass/fail status, and detailed academic remarks.
---
## 🌐 Live Demo
> Open `index.html` in any modern browser — no installation or server required.
---
## ✨ Features
- 📝 **Student Details Input** — Enter name and Roll/ID number
- 📚 **5-Subject Support** — Mathematics, Science, English, Social Studies, Computer Science
- 🧮 **Auto Calculation** — Total marks, percentage, and final grade computed instantly
- 📊 **Subject-Wise Breakdown** — Per-subject obtained marks, percentage, grade badge, and pass/fail status
- 🏆 **Performance Result Card** — Overall result with animated progress bar and academic remarks
- 📋 **Grading Rules Panel** — Built-in grade scale reference (A+ to F)
- ✅ **Pass/Fail Detection** — Requires minimum 35 marks per subject to pass
- 🔄 **Reset Form** — One-click form reset
